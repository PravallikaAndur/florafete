🌸 FloraFête

FloraFête is a website where users can **book decorations** and **buy customized bouquets** for special occasions like weddings, birthdays, anniversaries, and more. It provides an elegant and easy-to-use interface to make every celebration memorable.

✨ Features

🎉 Online booking for decoration services    

💐 Customizable bouquets for any occasion

🌐 Responsive design (works on desktop and mobile)

🖼️ Attractive gallery showcasing different event themes

🎨 Modern UI built using **HTML & CSS**


🛠️ Technologies Used

* **HTML5** for structure
* **CSS3** for styling and animations
* **GitHub Pages** for deployment

📌 Future Enhancements

* Add **backend** for real bookings and payments
* Add **user login** for personalized experiences
* Include **more themes** and seasonal offers
